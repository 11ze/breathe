# Breathe 整体风格试稿

本目录只用于 artboard/breathe-design-preview 的“本轮 · 整体微调”页，不修改应用及 designs/breathe 原型。

三个页面各有 current / proposed 两版，均从同一份本地原型复制并内联 CSS / JS。相同的展示规则将窗口置中，隐藏外层原型导航；画板为 760px 宽。当前时段固定为下午，菜单栏时钟固定为 14:00，便于直接比较。

## 推荐范围

1. 辅助文字与历史状态标签增大至 12px，“当前”标签为 11px；正文、标题与读秒不变。
2. 窗口 #F6F6F4、标题栏和表头 #F0F1EF、边框 #DFE2DD。历史预设名与摘要预设名使用正文色；绿色文字现改为深黑 #242B28；保留绿色操作背景与状态底色。
3. 时段图标改用同尺寸、同线宽 SVG 预览；原生实施时映射至 sunrise / sun.max / sunset / moon，需核对部署目标可用性。
4. 当前时段名称加粗；不增加整行底色。
5. 历史列宽随可用宽度分配，保留四列及展开详情。此项修正网页窄窗口呈现；原生最小窗口 860pt，尚未证实有同一问题。
6. 设计稿中应用窗口外的背景统一为 #F3F4F3，移除绿色渐变；当前版与建议版一致。此项只影响原型展示，不改原生桌面。最终确认后与其余已选修改一起实施。

7. 界面绿色文字改深黑 #242B28，包括开始、选中标签、摘要数值、当前标记与已完成状态；提前结束仍保留橙色状态字。
8. 菜单栏倒计时白字作为候选，新增 countdown-dark / countdown-light 两个静态对比画板。浅色菜单栏对比不足，正式实施前须确定适配策略。

深色模式暂缓。固定读秒、无阶段文字、历史展开详情沿用已选方向。

## 重复验证

在画板中展开任意页面并进入 PLAY。核对预设、通用、历史三组的左右版本；两侧文案、数据、窗口尺寸相同。切换自动 / 晨间 / 自定义，检查时段映射的显隐；自定义输入 3、3 应报错，改为 3、5 应恢复摘要。通用页切换日志开关，核对路径显隐。历史页展开记录，刷新后详情仍保持展开，状态文字完整。

按 760×840（预设）、760×760（通用/历史）检查；另检查 540×560 的设置视图与 920×760 的历史视图。允许内容区纵向滚动，不允许设置窗口被裁切；建议版历史在 760px 和 920px 宽度不应出现横向滚动。

本次为视觉试稿，采用浏览器实际检查而非 TDD 单元测试。页面状态仅存在内存；不读取配置或日志，不接入开机自启。没有原生运行证据。最终取舍以画板选择及用户说明为准。
