# Breathe 交互原型

以当前 Swift 源码为功能依据，采用 macOS 浅色窗口、系统字体和绿色重点色。入口为 `index.html`；不修改原生应用。

## 预览

从仓库根目录执行：

```bash
python3 -m http.server 4311 --bind 127.0.0.1 --directory designs
```

浏览器打开 <http://localhost:4311/breathe/>。无外部依赖，不需要联网；所有文件都在当前目录。

## 在线预览与发布

发布地址：<https://11ze.github.io/breathe/>。

`.github/workflows/pages.yml` 将整个 `designs/breathe/` 目录交给 `actions/upload-pages-artifact` 发布。`index.html`、`style.css` 和 `prototype.js` 使用相对引用，可在 Pages 的 `/breathe/` 子路径下加载，不需要构建或复制文件。

首次发布前，将仓库 Settings → Pages → Build and deployment → Source 设为 GitHub Actions。工作流提交并推送到 `main` 后会触发部署；之后只有原型目录或该工作流变更时自动发布，也可手动运行 Deploy design preview。手动发布仅允许 `main` 分支。首次部署成功前，在线地址不可用。

发布后确认 Actions 中部署成功，再逐个核对在线 `index.html`、`style.css`、`prototype.js` 与仓库版本一致，并执行下方的交互验收。部署失败时可继续使用本地预览；恢复上一版原型或工作流后重新部署即可回退，不影响应用配置和会话日志。

## 范围与来源

| 界面 | 功能依据 |
| --- | --- |
| 菜单、开始/停止、静音、退出 | `AppDelegate` |
| 倒计时、吸气/呼气、暂停后从吸气恢复 | `BreathingEngine` |
| 可拖动呼吸球、绿色吸气、橙红色呼气 | `BreathingPanelWindowController`、`BreathingCircle` |
| 自动时段、四种预设、自定义与校验 | `SettingsView`、`Preset`、`RatioValidator`、`BreathingConfig` |
| 通用开关、日志路径 | `SettingsView` |
| 历史字段、刷新、旧日志导入入口 | `HistoryView`、`SessionLogger` |

外层场景导航属于原型工具。设置窗口适当加宽、增加选中预设摘要，历史状态改为文字标签；这些是设计提案。呼吸球只显示阶段秒数或暂停符号。

## 可重复验证

1. 在设置中选择四种预设，核对比例与分钟数；选择“自动”核对上海时区的时段映射。
2. 选择“自定义”，输入吸气 3、呼气 3，出现周期不足提示，开始按钮禁用。改为 3、5 可开始；输入 2、10、空值或非整数，应提示无效。输入 7、6、时长 1，实际时长应为 1 分 5 秒。
3. 点击菜单栏“开始呼吸”，出现 3 秒倒计时，然后绿色吸气、橙红色呼气，菜单栏剩余时间递减。倒计时期间暂停禁用。
4. 吸气或呼气时暂停，秒数停止；继续时从新一轮吸气开始。拖动呼吸球应能在桌面范围内移动。
5. 停止后呼吸球隐藏；历史记录增加一条“提前结束”。关闭“记录会话日志”再开始并停止，不应增加记录。
6. 自定义 3、5、1 分钟，等待 70 秒（含 3 秒倒计时），应自然完成、隐藏呼吸球并增加 100% 的已完成记录。
7. 通用“声音提示”与菜单“静音”互相同步。关闭日志开关隐藏路径；开机启动开关仅演示状态。
8. 历史页“刷新”保持记录数，“导入旧版日志”加入一条标明用途的示例，不读取文件。
9. 退出后菜单栏入口与窗口隐藏；“重新打开演示”恢复入口。刷新页面恢复初始演示数据。
10. 在窄屏下检查窗口、表格滚动与菜单；用 Tab 操作按钮与表单。

## 演示边界

- 历史记录为固定示例及当前页面生成的临时记录，未读取 `sessions.csv`；刷新即重置。
- 开机自启、配置落盘、旧文件导入和系统通知均未接入；完成反馈用页面提示代替。提示音为浏览器合成音，不是 macOS 系统音效。
- 浏览器可能拦截原生快捷键，优先使用可见菜单；未接管 `⌘Q`，以免关闭浏览器。
- 使用当前浏览器时间和上海时区；不模拟系统窗口层级、所有桌面常驻或全屏辅助窗口。
- 自定义无效时禁用开始，便于检查输入；原生应用在该情况下会回退到 morning。原型省略自然完成时的 0.4 秒定格。
- 本交付为可交互视觉原型，未运行 Swift 构建和测试。未采用单元测试 Red → Green，以上浏览器步骤作为可重复验证方案。
